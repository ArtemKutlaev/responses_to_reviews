# 📊 Анализ и генерация ответов на отзывы (`responses_to_reviews`)

Интерактивное веб-приложение на базе **Streamlit**, которое выполняет автоматический анализ тональности клиентских отзывов с помощью машинного обучения и генерирует персонализированные ответы в зависимости от оценки.

---

## ⚙️ Логика работы приложения

1. **Позитивные отзывы (оценки 4–5):** Система выбирает случайный готовый шаблон благодарности из `src/services/templates/answers.py`.
2. **Негативные/нейтральные отзывы (оценки 1–3):** Задействуется **YandexGPT**, который анализирует текст и генерирует вежливый, конструктивный ответ с извинениями.
3. **Датасет:** Модель и проект обучены/протестированы на датасете из **1 360 отзывов**, спаршенных с маркетплейса Wildberries.

---

## 🛠 Стек технологий

* **Язык:** Python
* **Машинное обучение:** Scikit-learn (RandomForest, TF-IDF), Pandas, NLTK, PyMorphy3
* **LLM:** Yandex AI Studio SDK (YandexGPT)
* **Веб-интерфейс:** Streamlit
* **Инструменты:** Joblib, python-dotenv

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/ArtemKutlaev/responses_to_reviews.git
cd responses_to_reviews
```

### 2. Создание и активация виртуального окружения
```bash
python -m venv venv
```
* **Windows (PowerShell):**
  ```bash
  .\venv\Scripts\Activate
  ```
* **macOS / Linux:**
  ```bash
  source venv/bin/activate
  ```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка конфигурации (.env)
Создайте файл `.env` на основе примера `.env.example` и заполните необходимые ключи доступа (API-ключ Yandex Cloud и Folder ID).

### 5. Подготовка базы данных
1. Откройте файл `src/services/database.py`.
2. В строчке `data = pd.read_excel('Ссылка на excel файл с отзывами')` укажите актуальный путь к вашему Excel-файлу с данными.
   *Формат таблицы Excel:*
   | ИМЯ | РЕЙТИНГ | ОТЗЫВ |
   | --- | --- | --- |

3. Запустите скрипт создания базы данных, чтобы наполнить `data/database.db`.

### 6. Запуск приложения
Запустите веб-интерфейс с помощью Streamlit:
```bash
streamlit run main.py
```
После запуска в терминале появится локальная ссылка — откройте её в браузере.

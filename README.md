# 📊 Анализ и генерация ответов на отзывы (`responses_to_reviews`)

Интерактивное веб-приложение на базе **Streamlit**, которое выполняет автоматический анализ тональности клиентских отзывов с помощью машинного обучения и генерирует персонализированные ответы в зависимости от оценки.

---

## ⚙️ Логика работы приложения
1. **Предобработка отзыва:**  
   Текст отзыва приводится к нижнему регистру, очищается от пунктуации и стоп-слов, после чего выполняется лемматизация с помощью `NLTK` и `PyMorphy3`.

2. **Определение тональности:**  
   Обработанный текст преобразуется в TF-IDF вектор с помощью `TfidfVectorizer` и передаётся в обученную модель `CatBoost`.
   
   Модель рассчитывает вероятности принадлежности отзыва к трём классам:
   - `Negative` — негативный;
   - `Neutral` — нейтральный;
   - `Positive` — позитивный.

   Для определения итоговой тональности используются пороговые значения:
   - вероятность `Positive` ≥ **0.85** → `Positive`;
   - вероятность `Negative` ≥ **0.70** → `Negative`;
   - в остальных случаях → `Neutral`.

3. **Формирование ответа:**
   - для **позитивных** отзывов система выбирает случайный готовый шаблон благодарности из `src/services/templates/answers.py`;
   - для **негативных и нейтральных** отзывов используется **YandexGPT**, который на основе текста отзыва, имени пользователя и названия товара формирует вежливый и конструктивный ответ.

4. **Машинное обучение:**  
   Для обучения модели используются отзывы с маркетплейса Wildberries. Тексты проходят предварительную обработку и преобразуются в числовое представление с помощью TF-IDF. После этого на подготовленных данных обучается модель `CatBoost`.

5. **Хранение обученных компонентов:**  
   Обученная модель и TF-IDF-векторизатор сохраняются в формате `.pkl` с помощью `Joblib` и загружаются при запуске приложения.

Из массива сырых данных, превышающего 70 000 записей, модуль src/services/database.py производит интеллектуальный отбор наиболее релевантных отзывов.
Итоговая выборка оптимизирована и распределена по шкале оценок следующим образом:

    Оценка 5: 2 000 отзывов

    Оценка 1: 1 874 отзыва

    Оценка 4: 1 682 отзыва

    Оценка 3: 1 300 отзывов

    Оценка 2: 624 отзыва

## 🛠 Стек технологий

* **Язык:** Python
* **Машинное обучение:** Scikit-learn (TF-IDF),CatBoost, Pandas, NLTK, PyMorphy3
* **LLM:** Yandex AI Studio SDK (YandexGPT)
* **Тестирование:** Pytest
* **Контейнеризация:** Docker
* **Веб-интерфейс:** Streamlit
* **Инструменты:** Joblib, python-dotenv

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/ArtemKutlaev/responses_to_reviews.git
cd responses_to_reviews
```

### 2. Создание и активация виртуального окружения
```bash
python -m venv venv
```
* **Windows (PowerShell):**
  ```bash
  .\venv\Scripts\Activate
  ```
* **macOS / Linux:**
  ```bash
  source venv/bin/activate
  ```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка конфигурации (.env)
Создайте файл `.env` на основе примера `.env.example` и заполните необходимые ключи доступа (API-ключ Yandex Cloud и Folder ID).

### 5. Подготовка базы данных
1. Откройте файл `src/services/database.py`.
2. В строчке `data = pd.read_excel('Ссылка на excel файл с отзывами')` укажите актуальный путь к вашему Excel-файлу с данными.
Таблицу можно спарсить с помощью кода https://github.com/progmat64/wildberries_review_parser?ysclid=ms17r0h625437659042
   *Формат таблицы Excel:*
   | ИМЯ | РЕЙТИНГ | ОТЗЫВ |
   | --- | --- | --- |

3. Запустите скрипт создания базы данных, чтобы наполнить `data/database.db`.

### 6. Обучение модели
Запустите обучение с помощью
```
python -m src.ml.train
```

### 7_1. Запуск приложения локально
Запустите веб-интерфейс с помощью Streamlit:
```bash
streamlit run main.py
```
После запуска в терминале появится локальная ссылка — откройте её в браузере.

### 7_2. Запуск приложения через Docker
Для запуска приложения через Docker необходимо убедиться, что Docker установлен и запущен.
Сначала соберите Docker-образ из корневой директории проекта:
```bash
docker build -t wb-reviews .
```
После успешной сборки запустите контейнер:
```bash
docker run --rm -p 8501:8501 --env-file .env wb-reviews
```
После запуска в терминале появится ссылка Local URL. Откройте её в браузере.

### Тесты Pytest
Для запуска автоматических тестов выполните:
```bash
python -m pytest -v
```
